Why it matters

Theft density map

See where and when thefts happen on campus so you can make safer parking and locking choices — fully anonymous, no names shown.

Reviewed, not raw

Every report is screened by AI and then a human before it reaches the map or police — so the data stays trustworthy.

Helps UMPD recover bikes

Detailed, sorted exports go to UMPD with the info they need to help recover stolen bikes and scooters.

Monthly campus report

A one-page public summary each month — hotspots, lock failures, and one recommendation — so reporters see it made a difference.
